# Maddy Monte Fitness Website

Landing page for Maddy Monte Fitness featuring reformer pilates, body sculpting, and strength training.

## 🚀 How to Deploy to Vercel

### IMPORTANT: Correct Folder Structure
```
maddy-monte-fitness/
├── index.html
├── vercel.json
└── package.json
```

### Option 1: Deploy with GitHub (Recommended)

1. **Create a GitHub account** at [github.com](https://github.com)

2. **Create a new repository:**
   - Click the "+" icon → "New repository"
   - Name: `maddy-monte-fitness`
   - Make it Public
   - Click "Create repository"

3. **Upload ALL three files:**
   - Click "uploading an existing file"
   - Upload: `index.html`, `vercel.json`, and `package.json`
   - Make sure they're in the ROOT folder (not in a subfolder)
   - Commit the changes

4. **Deploy to Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Click "Sign Up" and use your GitHub account
   - Click "Add New..." → "Project"
   - Import your `maddy-monte-fitness` repository
   - Click "Deploy"

### Option 2: Deploy Directly to Vercel

1. **Go to [vercel.com](https://vercel.com)** and create an account

2. **Download ALL files from this project:**
   - index.html
   - vercel.json
   - package.json

3. **Create a folder** on your computer called `maddy-monte-fitness`

4. **Put ALL THREE files** in that folder (not in a subfolder!)

5. **Deploy:**
   - Log into Vercel
   - Click "Add New..." → "Project"
   - Drag and drop the entire `maddy-monte-fitness` folder
   - Click "Deploy"

## 🔧 Troubleshooting

### Getting a 404 Error?

**Check these things:**

1. ✅ File is named exactly `index.html` (lowercase, no spaces)
2. ✅ `index.html` is in the ROOT folder, not in a subfolder
3. ✅ Both `vercel.json` and `package.json` are present
4. ✅ You uploaded the entire folder, not just the HTML file

### Files are in a subfolder?

If you accidentally uploaded files to a subfolder like `maddy-monte-fitness/maddy-monte-fitness/index.html`:
- Delete the project in Vercel
- Re-upload with the correct structure

### Still not working?

In Vercel:
1. Go to your project → "Settings" → "General"
2. Under "Build & Development Settings"
3. Set "Output Directory" to `.` (just a period)
4. Click "Save"
5. Go to "Deployments" tab
6. Click the three dots on the latest deployment → "Redeploy"

## 🔄 How to Update Your Site

### If you used GitHub:
1. Go to your repository on GitHub
2. Click on `index.html`
3. Click the pencil icon (Edit)
4. Make your changes
5. Click "Commit changes"
6. Vercel will automatically redeploy!

### If you uploaded directly:
1. Make changes to your local `index.html`
2. Go to Vercel → Your project → "Deployments"
3. Drag and drop the updated folder again

## 🌐 Custom Domain (Optional)

To use a custom domain like `maddymonte.com`:

1. Buy a domain from Namecheap, GoDaddy, or Google Domains
2. In Vercel: Project → "Settings" → "Domains"
3. Add your domain
4. Follow Vercel's DNS instructions
